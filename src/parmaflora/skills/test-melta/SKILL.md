# melta とは

Tyggja が作った原本 `<出力フォルダ>/structure/original/` を元に、編集した版 `<出力フォルダ>/structure/<版の名前>/` を作る道具です。
版は原本と同じ形式です。
編集者は、版の JSON を直接書き換えず、必ず `melta` コマンドを通して編集します。
ID の約束、直す前の文の記録、JSON の書式を、道具が保証するためです。

どのコマンドも、最初の引数は `<出力フォルダ>`（`structure/` の親）です。
結果は標準出力、エラーは標準エラーに出ます。成功は終了コード 0、失敗は 0 以外です。

# 約束

## original を書き換えない

1. `original` は原本です。`melta` の編集コマンドは `original` を拒否します。
2. 編集は、必ず `melta new` で作った版に対して行います。

## ID の約束

1. 他の要素の ID は、振り直さない。
2. 足す文の ID は、入れ物（パラグラフや item）の ID + `.` + 番号。番号は、その入れ物でこれまでに使われた番号（今ある ID と消した ID の両方）の最大 + 1。道具が決めます。
3. 消した ID は `edition.retired_ids` に入り、使い回されない。
4. 並び順は配列の順で決まる。ID の大小や形に頼らない。

## JSON を直接書き換えない

JSON のファイルを、エディタやシェルで直接書き換えてはいけません。
書式（センテンス 1 つを 1 行）、`origin` と `note`、`index.json` の整合を、道具が保ちます。

# 読むコマンド

| コマンド | 内容 |
|---|---|
| `melta list <出力フォルダ>` | 版の一覧と系譜。1 行に 1 つ、タブ区切りで `name base editor created_at`（原本は `original - - -`） |
| `melta toc <出力フォルダ> <版>` | 目次（`# toc`）とファイルの一覧（`# files`）。目次は `ID<タブ>見出し<タブ>ファイル`、ファイルは `ファイル<タブ>ID<タブ>chars<タブ>json_chars` |
| `melta show <出力フォルダ> <版> <ID>` | ID の要素を JSON で出す |
| `melta show <出力フォルダ> <版> <表のID> --rows 0-19` | 表の行を絞る（セルの `row` の値、両端を含む） |
| `melta show <出力フォルダ> <版> --file <ファイル名>` | 1 ファイルをそのまま出す |

# 版を作るコマンド

```
melta new <出力フォルダ> --from <元の版> --editor <編集者名>
```

1. 元の版を全部コピーして、新しい版を作ります。作った版の名前（`01_ocr-fix` など）を標準出力に出します。
2. 版の名前は `<2 桁の連番>_<編集者名>` です。連番は、`structure/` にある版の連番の最大 + 1 で、道具が決めます。
3. 編集者名は、英小文字・数字・ハイフンだけです。
4. 元の版から持ち越した `origin` と `note` は消えます。`origin` は、1 つ前の版（`edition.base`）との対応だけを持ちます。

# 編集するコマンド

`original` を指定すると、必ず拒否されます。
成功すると、対象の ID を標準出力に出します。

| コマンド | 内容 |
|---|---|
| `melta set-text <出力フォルダ> <版> <ID> --text <文> [--note <理由>]` | センテンス（パラグラフと item の両方）とキャプションの文を直す |
| `melta set-text … <表のID> --cell <row>,<col> --text <文>` | 表のセルを直す |
| `melta set-text … <図のID> --index <n> --text <文>` | 図の中の文字を直す（`n` は 0 から。必須） |
| `melta insert <出力フォルダ> <版> --after <センテンスID> --text <文> [--note <理由>]` | センテンスを、指定した文の後ろに足す。新しい ID を出す |
| `melta insert <出力フォルダ> <版> --first-in <パラグラフやitemのID> --text <文>` | センテンスを、入れ物の先頭に足す |
| `melta split <出力フォルダ> <版> <センテンスID> --text <文1> --text <文2> … [--note <理由>]` | センテンスを分ける。1 つ目が元の ID を引き継ぎ、2 つ目以降に新しい ID が付く。ID を順に出す |
| `melta delete <出力フォルダ> <版> <センテンスID> [--note <理由>]` | センテンスを消す。入れ物の最後の 1 文は消せない |

1. `--text` は、直した後の全文を書きます（一部ではありません）。
2. `--note` には、直した理由を書きます。
3. 直した要素には、`origin`（直す前の版の ID と文）と `note` が付きます。同じ版で同じ要素を 2 回直しても、`origin` は最初のままです。直した結果が元の文に戻ったら、`origin` と `note` は消えます。
4. 見出し（セクションの title）の文字は、直せません。
5. 構造を変える編集（見出し、セクションの分割・統合、ファイルの分け直し）は、できません。

# 確かめるコマンド

| コマンド | 内容 |
|---|---|
| `melta check <出力フォルダ> <版>` | 形式を確かめる。問題を 1 行ずつ出し、あれば終了コードが 0 以外。問題が無ければ「問題はありません」 |
| `melta diff <出力フォルダ> <版A> <版B>` | ID で対応を取り、変わった・足された・消えた要素を Markdown で出す（直す前・直した後・理由）。差分が無ければ、その旨を 1 行で出す |
| `tyggja structure <出力フォルダ> --check --edition <版>` | Tyggja 側の確認。ファイルの欠け、`section_ref` の先、ID の重複、JSON の誤りを確かめる |

`melta check` が確かめること:

1. `index.json` と分けたファイルが、2 つのスキーマに合っている
2. ID が、版の全体で重複しない
3. `section_ref` が指すファイルがある
4. `index.json` の `files`・`toc` と、実際のファイルが合っている
5. `edition.retired_ids` の ID が、版の中に残っていない
6. `original` 以外の版では、`edition.name` がフォルダ名と同じ

# 編集の流れ

1. `melta new` で版を作る
2. `melta toc` と `melta show --file` で読む
3. `melta set-text` などで直す
4. `melta check` で確かめる
5. `melta diff` で、元の版との差分を確かめて報告する
